# 因子泄露检测作业说明

## 1. 验收结论与阅读顺序

本作业实现了基于**时间前推重算**的因子泄露检测器，并用独立的**未来价格扰动**实验复核三类未来价格依赖。最终复验：**27 项自动化测试通过**；默认管线检查 **25 个因子 × 180 行数据**，6 个故意泄露的因子全部被标记，19 个历史因子均未被标记。扩展实验完成 7 个案例，两种方法有 1 个预期分歧。

先看 [默认报告](../../outputs/delivery-review/default/report.md) 了解作业结果，再看 [逐行 JSON](../../outputs/delivery-review/default/violations.json) 核对证据。要比较两种方法，再打开 [扩展实验报告](../../outputs/delivery-review/experiments/report.md)。这些链接指向本地生成的文件；新克隆中需按本文命令生成。

| 指南要求 | 验收证据 |
| --- | --- |
| 检出有未来依赖的因子；正常预热缺失不误报 | 默认样本的六个正例全部命中且没有历史因子出现在疑似列表；另有公式和缺失值测试。 |
| 覆盖同日多股票、输入顺序、索引对齐和容差 | 用同日排名、乱序输入、重复原始索引及倒序返回的因子验证按行对齐；绝对差恰等于容差时通过，超过时记录。 |
| 一条可用的管线输出三份一致的报告 | CLI 端到端测试核对 CSV、JSON 和 Markdown 的因子、信号类型与比例。仍保留检测器未实现时的错误提示测试。 |
| 用自行构造的因子和数据复核 | 自定义滞后收益已注册；测试另有双股票小样本、截面排名和自定义未来收盘价。扩展实验再覆盖全样本拟合和行数依赖。 |
| 说明方法、结果、局限与报告示例 | 本文提供分步算法、公式、数值例子和复现命令。姓名分支提交、推送仍是单独的交付步骤。 |

## 2. 数据、时点与项目结构

默认使用模拟器的固定种子 42，共 3 只虚拟股票（AAA、BBB、CCC），每只 60 个工作日，日期从 2021-01-04 到 2021-03-26。每行有日期、股票代码、开盘价、最高价、最低价、收盘价、成交量和日收益率。股票和日期共同标识一行；时间窗口中的“5 期”指**该股票的 5 条相邻观测**，不等于 5 个自然日。数据是用于验证算法的合成行情。

新增量价因子的计算时点约定为**当日收盘后**，所以当天完整 OHLCV 可用。同日跨股票比较也以此为前提。若信号要在开盘前生成，就需要重新定义可见字段和截止时间，通常还要滞后当天才确定的输入。

| 文件 | 作用 |
| --- | --- |
| [simulator.py](../../src/leak_detection/simulator.py)、[data.py](../../src/leak_detection/data.py) | 生成可复现行情；加载 CSV，把日期解析为时间戳并按股票、日期排序。 |
| [因子注册表](../../src/factors/__init__.py)、[示例因子](../../src/factors/sample_factors.py)、[量价因子](../../src/factors/ohlcv_factors.py) | 每个因子接收 DataFrame 并返回可按输入索引对齐的一维 Series。注册表传入函数和说明。 |
| [detector.py](../../src/leak_detection/detector.py) | 按日期前推重算、绝对容差比较和差异记录；另提供未来收盘价扰动。 |
| [pipeline.py](../../src/leak_detection/pipeline.py)、[reporting.py](../../src/leak_detection/reporting.py) | 装载行情和注册表、调用检测器，将同一份结果导出为三种格式。 |
| [实验因子](../../src/factors/experiment_factors.py)、[实验运行器](../../src/leak_detection/experiments.py) | 独立运行七案例对比；预期标签用于实验核对，不参与检测判定。 |

## 3. 前推重算怎么做

1. **检查输入。** 实体列、时间列必须存在，实体与日期不能缺失，实体和日期的组合不能重复。容差必须是有限的非负数。
2. **稳定对齐。** 先按股票、日期排序，再建立唯一内部行号。原始索引即使不连续或重复，也不会导致同一股票与日期被配错。若因子返回的 Series 顺序不同，可按索引重排；缺行、重复索引或索引集合不符会报错。
3. **计算基准。** 每个因子在完整数据上算一次。每次用独立的数据副本调用因子，避免它修改输入后污染其他计算。
4. **模拟当时可见数据。** 枚举每个检查日 `as_of`，按日期筛选 `date <= as_of` 的全部记录并重算。即使数据按股票排列，当日全部股票仍会保留。同日排名或均值因子因此可以正确使用完整截面。
5. **只比较检查当天。** 将当天每只股票的完整计算值与前推值按行号对齐。默认绝对容差为 `1e-9`，不叠加相对容差。绝对差超过容差，或仅一侧缺失时记录差异。双方均缺失视为一致。
6. **汇总证据。** 每个发生差异的因子记录一项 `forward_replay_mismatch`，附上分子、分母以及每行的日期、股票、基准值和重算值。因子的 `is_intentional_leak` 标记只说明教学预期，检测判定根据数值重算。

例如，有 A、B 两只股票和第 1、2、3 日。检查第 2 日时，重算输入是 A、B 的第 1、2 日共四行；比较的是第 2 日 A、B 两行。第 1 日由自己的检查轮次覆盖。若 A 第 2 日因子用了 A 第 3 日收盘价，全样本有值而前推重算缺失，便出现可复核的差异。

## 4. 默认因子库：19 个历史因子与 6 个故意泄露因子

下文以 `P[t]` 表示当前股票收盘价，`V[t]` 表示成交量，`O/H/L/C` 表示当期开高低收。尾随窗口含当天。16 个新增历史因子的设计参考了 [Qlib Alpha158 的公开特征配置](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/loader.py#L889)，这里使用本仓库的命名、窗口和缺失值约定，无需安装 Qlib。

| 历史因子或系列 | 数量 | 公式或说明 |
| --- | ---: | --- |
| `factor_momentum_ema` | 1 | 按股票计算日收盘收益，取跨度 3 的指数移动平均并滞后一条。 |
| `factor_volume_mean5` | 1 | 按股票计算 5 期平均成交量，至少需要 3 个值，并滞后一条。 |
| `factor_lagged_return` | 1 | 自定义因子。按股票取上一条 `ret_1d`；首行或上一条收益缺失时返回缺失。 |
| `factor_candle_body_ratio` | 1 | 带符号实体比例，`(C-O)/(H-L)`。 |
| `factor_upper_shadow_ratio` | 1 | 上影线比例，`(H-max(O,C))/(H-L)`。 |
| `factor_lower_shadow_ratio` | 1 | 下影线比例，`(min(O,C)-L)/(H-L)`。 |
| `factor_candle_close_position` | 1 | 带符号收盘位置，`(2C-H-L)/(H-L)`。 |
| `factor_close_momentum5/20` | 2 | `P[t]/P[t-n]-1`，分别取 5 期和 20 期。 |
| `factor_close_ma_ratio5/20` | 2 | 尾随 5/20 期平均收盘价除以当日收盘价。 |
| `factor_close_std_ratio5/20` | 2 | 尾随 5/20 期收盘价的样本标准差（分母为样本数减一）除以当日收盘价。 |
| `factor_range_position5/20` | 2 | `(当前收盘-窗口最低价)/(窗口最高价-窗口最低价)`，窗口为尾随 5/20 期。 |
| `factor_volume_ma_ratio5/20` | 2 | 尾随 5/20 期平均成交量除以当日成交量。 |
| `factor_price_volume_corr20` | 1 | 尾随 20 期的收盘价与 `log(1+成交量)` 的 Pearson 相关；恒定序列的相关性未定义。 |
| `factor_up_day_share20` | 1 | 最近 20 个可计算的逐期价格变化窗口里，上涨天数占比；需要 21 条价格观测。 |

新增滚动因子按股票分别计算。完整窗口不足时保留缺失；零振幅、零分母和无法定义的相关性也保留缺失。某个历史因子没有出现在报告中，并不代表管线没检查它：报告备注记录了总检查数量，疑似列表只显示发生差异的因子。

| 故意泄露因子 | 注入的未来信息 | 差异行数 / 比较行数 | 报告比例 |
| --- | --- | ---: | ---: |
| `factor_future_return` | 用下一条收盘价算当前行的未来日收益。 | 177 / 180 | 0.983 |
| `factor_leaky_next_upper_shadow_ratio` | 将下一条观测的上影线比例提前到当前行。 | 177 / 180 | 0.983 |
| `factor_leaky_forward_momentum5` | 以 `P[t+5]` 代替历史端点，计算前向收益。 | 165 / 180 | 0.917 |
| `factor_leaky_centered_close_ma_ratio5` | 五期均价窗口从 `[t-4,t]` 改为 `[t-2,t+2]`。 | 168 / 180 | 0.933 |
| `factor_leaky_forward_range_position5` | 用 `[t+1,t+5]` 的最高价和最低价衡量当前收盘位置。 | 165 / 180 | 0.917 |
| `factor_leaky_full_sample_volume_ma_ratio` | 把尾随均量改为该股票全样本均量，隐式纳入未来成交量。 | 177 / 180 | 0.983 |

计数可以进一步核对。下一期因子在每只股票的末行没有下一期，全量与截断都缺失，因此各有 59 行差异。前向五期因子的末五行也没有足够未来观测，各有 55 行差异。居中五期因子在全样本首尾各两行缺窗口，在中间 56 行的前推值会缺少未来两期。全样本均量因子到最后一个检查日才拿到与基准相同的完整窗口。本次模拟中其余日期均出现差异。

## 5. 扩展实验：固定历史，改变未来价格

独立命令使用同一份固定种子行情。对每个仍有未来行的检查日，从未修改的全量行情复制一份，仅把 `date > as_of` 的收盘价乘以 1.5。保留所有记录、日期与股票，并让检查日及此前的数值保持不变。重算后只与该日的全量基准对比，复用绝对容差和缺失值规则。最后一天无未来记录可扰动，所以少比较 3 行，分母为 177。

| 案例 | 因子含义 | 前推重算 | 未来价格扰动 |
| --- | --- | ---: | ---: |
| 前向三期市场相对收益 | 当前到未来三期的复合收益减同日横截面均值。 | 171/180 | 171/177 |
| 尾随三期市场相对收益 | 保留同日横截面计算，改用截至当天的尾随三期收益。 | 0/180 | 0/177 |
| 居中波动率调整动量 | 五期历史动量除以居中五条日收益的总体波动率，分母含未来两条。 | 159/180 | 159/177 |
| 尾随波动率调整动量 | 同样的动量分子，分母只用截至当天的五条日收益。 | 0/180 | 0/177 |
| 全样本标准化复合动量 | 五期动量的当天横截面排名与个股全样本 Z 分数等权相加。 | 162/180 | 162/177 |
| 历史标准化复合动量 | 同样的排名和权重，Z 分数只用严格早于当天的历史动量拟合。 | 0/180 | 0/177 |
| 下一行是否存在 | 只检查该股票在输入中是否还有后一条记录。 | 177/180 | 0/177 |

上表数值是“差异行数 / 比较行数”。第七个案例展示了方法边界：截断会移除未来行，把“存在”从 1 变为 0；只修改未来价格时行仍然存在，结果保持不变。价格扰动的零差异在此有明确原因。它也可能漏掉只使用未来成交量、最高价或最低价的因子，所以这七个案例与默认 25 因子库分别运行。

## 8. 已知局限与下一步

- **历史时点可得性。** 若先把未来发布的财报、事后复权值、最新修订版本或事后筛选的股票池写进历史行，截断未来行可能看不出变化。实际回测需另行检查发布时间、数据版本、股票池和信号可用时点。
- **输入与计算假设。** 因子应对给定输入给出稳定结果。外部数据访问、随机状态或缓存造成的不一致，也可能被标为差异，需要回到证据定位原因。
- **扰动覆盖范围。** 本实验只以固定比例改变未来收盘价。其他字段、行数依赖或对缩放不敏感的计算可能没有响应。实验采用唯一行索引的模拟面板；若输入索引重复，扰动函数会先分配内部行号，对比双方一致，但因子函数不会看到原重复标签。
- **规模与外推。** 两种方法都要逐日重算；日期和因子数量上升会增加开销。固定种子的 180 行数据用于功能验证，无差异不能证明真实行情或所有输入下不存在泄露。
