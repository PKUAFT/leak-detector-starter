# Design

## Context
因子函数接收行情 DataFrame，并返回可按输入索引对齐的数值 Series。

## Goals / Non-Goals
保留检测器和报告接口，验证三个已有因子的识别结果。本练习的证据仅限给定数据中可通过截断重算观察到的未来行依赖。

## Decisions
- 先检查实体和时间键，再按实体及时间排序并分配唯一行索引。每次调用使用数据副本。
- 每个因子计算一次完整基准，并按时间点重算；每次保留截至该时点的整份截面，只比较该时点的行。
- 使用绝对误差容差；双侧缺失一致，单侧缺失为差异。每个疑似因子记录一项结果，置信度为差异行数除以比较行数。
- 日期和缺失值转换为可导出的值，便于报告复核。

## Risks / Trade-offs
逐日重算的开销随日期数增长。因子应是确定性的；输入字段实际何时发布以及数据修订等问题需要另外核查。
