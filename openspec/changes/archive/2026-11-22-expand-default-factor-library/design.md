# Design

## Context
默认管线从注册表读取四个因子；独立扩展实验直接传入另一套案例。默认数据已有日频 OHLCV。

## Goals / Non-Goals
扩充默认量价因子库，保留可复现的泄露对照。公式参考 Alpha158，采用当前仓库的输入和缺失值规则。

## Decisions
- 当日 K 线实体、上下影线和收盘位置按振幅归一化。其余因子为 5/20 条观测的动量、均价、价格波动、区间位置和均量（各两个），以及 20 条观测的量价相关、上涨比例（各一个）。
- 因子按股票使用截至当日的右侧对齐窗口，假定当天收盘后计算。完整窗口不足、分母为零或相关性不可定义时保留缺失；输出沿用输入索引。
- 默认报告保持原有格式，通过报告备注确认检查数量。

## Risks / Trade-offs
当日 OHLCV 适用于收盘后计算。开盘前使用时需要另行滞后。固定种子的模拟数据用于功能验收。
