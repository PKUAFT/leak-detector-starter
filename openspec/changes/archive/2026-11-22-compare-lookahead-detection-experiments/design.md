# Design

## Context
现有 `detect_leaks` 用全量行情做基准，按日截断后重算并对齐当天所有股票。它支持直接传入一组因子。当前默认注册表有四个因子，现有管线测试依赖默认报告只标记未来收益。

## Goals / Non-Goals
以相同的模拟面板和案例比较前推重算与未来价格扰动。使用独立实验命令；AST 扫描、真实数据发布时间和供应商修订留作后续研究。

## Decisions

| 案例 | 因子计算 | 前推重算预期 | 扰动预期 |
|---|---|---|---|
| 前向市场相对收益 | 计算每只股票从 `t` 到 `t+3` 的三日复合收益，再减同日有效股票的等权平均收益 | 标记 | 标记 |
| 历史市场相对收益 | 同样做横截面去均值，收益窗口改为 `t-3` 到 `t` | 无差异 | 无差异 |
| 居中波动率调整动量 | 用过去五日动量除以五个日收益的居中窗口波动率，分母包含未来两日 | 标记 | 标记 |
| 尾随波动率调整动量 | 保留同一动量分子，分母改用截至当天的五个日收益 | 无差异 | 无差异 |
| 全样本标准化复合动量 | 五日动量的当日横截面百分位，与按个股全样本统计量计算的动量 Z 分数等权相加 | 标记 | 标记 |
| 历史标准化复合动量 | 保留同样的横截面百分位和权重，仅用该股严格早于当天的动量序列拟合 Z 分数 | 无差异 | 无差异 |
| 下一行存在标记 | 指示该股票在输入数据中是否还有后续观测 | 标记 | 无差异 |

- 假定因子在当天收盘后计算，`t±n` 指同一股票向前或向后第 `n` 条观测。三日复合收益为区间末价除以初价再减一，横截面均值和排名以有效值计算，至少需两只股票；排名使用并列平均百分位。五日动量为 `close[t] / close[t-5] - 1`。波动率用完整五个日收益的总体标准差，Z 分数拟合至少需五个有效动量值，并用总体标准差；缺失或零波动率、零标准差保留缺失。
- 实验一沿用 `detect_leaks`，通过独立的实验因子集合传入。预期标签独立于检测，比较完成后才用于报告。每个案例记录未来依赖发生在收益窗口、波动率窗口、拟合样本还是面板结构。
- 实验二按同一日期串行重算。每个有未来行的检查日都从原始全量面板独立复制一份，只把 `date > as_of` 的 `close` 乘以固定系数 1.5。保留日期、股票、行数、索引以及当天和以前的所有值。实验因子只读 `close` 或面板结构，因此无需重算行情里的 `ret_1d`。
- 对齐股票和日期，只比较检查日的完整截面。使用与前推重算相同的绝对容差和缺失值一致性规则。扰动跳过没有未来行的最后一天，分别记录方法的比较行数与差异数。
- 用 `tests/tools/run_lookahead_experiments.py --output outputs/lookahead-experiments` 运行固定种子的模拟数据，输出 `comparison.csv` 和 `report.md`，列出每个案例的预期、两种结论、比较行数、差异行数和至少一条可核查证据。

## Risks / Trade-offs
复合计算可能抵消某一日的影响。例如，两只股票的前向收益相等时，横截面去均值后仍为零。双股票测试面板应有不同、非恒定的收益路径，覆盖全部预热期，并手算市场平均、波动率或拟合统计量的关键中间值。加入周末或缺交易记录的真实数据前，需另行约定窗口语义。固定价格扰动无法发现仅依赖未来行数、其他未改字段或真实字段发布时间的情况；两个方法的差异保留在报告中。
